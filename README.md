# Голосовой Ассистент Задач и Встреч

Интеллектуальный голосовой ассистент для управления личным расписанием, задачами, встречами и напоминаниями на естественном русском языке.

## Ключевые возможности

1. **Естественное создание задач и встреч**:
   - «Напомни мне завтра в 10 утра позвонить Ивану»
   - «В пятницу нужно отправить отчет»
   - «Добавь встречу с командой завтра в 15:00»
   - «Поставь задачу купить билеты до конца недели»

2. **Интеллектуальное распознавание речи (STT)**:
   - Распознавание через **Groq Whisper** (`whisper-large-v3-turbo` / `whisper-large-v3`) со скоростью ответа 300-500 мс.
   - Поддержка браузерной записи через `MediaRecorder` и загрузки готовых аудиофайлов (`.ogg`, `.wav`, `.mp3`, `.m4a`).
   - Автоматический fallback на Web Speech API и внешние сервисы (Yandex SpeechKit, OpenAI Whisper).

3. **Telegram-бот (@testovoe_g0rkyc0de_bot)**:
   - Создан на `aiogram 3.x`, упакован в Docker-контейнер `voice-assistant-bot`.
   - Принимает голосовые сообщения (OGG Opus) и текст, автоматически распознает намерение и синхронизирует события с базой данных.
   - Поддерживает инлайн-клавиатуры для быстрых действий (отметить выполненным, удалить, отменить).

4. **Уточняющий диалог (Multi-turn Dialog)**:
   - Если пользователь не назвал обязательные параметры (например, «Поставь встречу с Иваном завтра»), ассистент сохраняет контекст сессии и задает уточняющий вопрос: «На какое время поставить встречу?». При следующем ответе («в 15:00») встреча создается.

5. **Анализ конфликтов расписания**:
   - При создании встреч в реальном времени проверяется пересечение по дате и времени. В случае наложения ассистент голосом и в интерфейсе предупреждает о занятости слота.

6. **Гибридный семантический поиск по старым событиям**:
   - «Найди задачу про презентацию»
   - «Когда у меня была встреча с Иваном?»
   - Поиск работает без точного совпадения за счёт SQLite FTS5, русского стемминга и кластеров синонимов (договор ↔ контракт ↔ соглашение ↔ акт, презентация ↔ слайды ↔ питч ↔ демо).

7. **Двойной интерфейс**:
   - **Список дел**: фильтры («Все», «Задачи», «Встречи», «Выполненные»), живой поиск, быстрое завершение и удаление.
   - **Интерактивный календарь**: сетка месяцев с точками событий, просмотр расписания на выбранную дату.
   - **Экспорт .ics**: выгрузка расписания в формат iCalendar для импорта в Google Calendar, Apple Calendar или Яндекс.Календарь.

## Автоматическая синхронизация (Ноутбук ↔ VPS)

### Способ 1. Мгновенный деплой с ноутбука в 1 команду
Для отправки изменений и автоматического обновления на VPS:
```bash
bash deploy/deploy_from_local.sh
```
Скрипт делает `git push origin main`, подключается по SSH к серверу `31.77.203.213`, делает `git pull` и перезапускает Docker-контейнеры.

### Способ 2. Авто-пулл на сервере через Cron (Zero-Setup)
Выполните один раз на VPS в директории проекта:
```bash
bash deploy/setup_auto_pull.sh
```
Сервер будет каждую минуту опрашивать ветку `main`, автоматически подтягивать коммиты и пересобирать контейнеры.

### Способ 3. GitHub Actions CI/CD
В репозитории настроен `.github/workflows/deploy.yml`. При каждом пуше в ветку `main` GitHub запускает пайплайн деплоя через SSH.

## Развертывание и запуск

### 1. Запуск через Docker Compose (на VPS или локально)

```bash
# Клонирование
git clone https://github.com/Britnispirs/testovoe_g0rkyc0d3.git
cd testovoe_g0rkyc0d3

# Настройка переменных окружения
cp .env.example .env
nano .env

# Запуск стека (FastAPI + Telegram-бот)
docker compose up -d --build
```

### 2. Локальный запуск без Docker

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt

# Запуск бэкенда
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload

# Запуск Telegram-бота (в отдельном терминале)
python3 -m bots.telegram.main
```
